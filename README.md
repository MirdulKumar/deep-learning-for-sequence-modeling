

# Sequence Learning and Attention-Based Deep Learning

This project explores deep learning architectures for sequential data using **PyTorch**.

## Models
- Recurrent Neural Network (RNN)
- Long Short-Term Memory (LSTM)
- Gated Recurrent Unit (GRU)
- Transformer and Self-Attention

## Objectives
- Implement and compare sequence-learning architectures.
- Explore long-term dependency learning.
- Apply deep learning models to Human Activity Recognition.
- Build a character-level language model using Transformer architecture.

## Technologies
Python · PyTorch · NumPy · Pandas · Matplotlib · Scikit-learn
